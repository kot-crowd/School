# Эталонное решение для проекта «Крестики-нолики»
1. Выполните задание «Разработайте игру "Крестики-нолики"». Если вы его не завершили, вернитесь к нему [по этой ссылке](https://github.com/EdusonPython/Python-Projects/blob/tic-tac-toe/README.md). 
2. Когда проект будет готов, скачайте файл `tic-tac-toe.py` из этой ветки репозитория. В нем вы найдете эталонное решение задания.
3. Сравните свой код с решением. При необходимости внесите изменения в свой код.
<p>
<aside>
⚡ Этот проект не проходит проверку у код-ревьюера. Проверьте свой код самостоятельно по эталонному решению, которое разработал эксперт. Ваше решение может отличаться от кода эксперта, при этом важно, чтобы в вашем коде не было критичных ошибок и соблюдалась логика, которая отражена в эталонном решении. Если ваше решение сильно отличается от эталонного, проверьте, корректно ли работает программа. Протестируйте ее в разных ситуациях — в ситуации победы, проигрыша и ничьи. Если все работает корректно, вы справились с заданием.
